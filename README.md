# Русские шахматы — Android

Мобильная версия игры «Русские шахматы» с составными ходами.

## Реализовано

- Android 9+ (min API 28).
- Вертикальная ориентация.
- «Человек против ИИ».
- «Два человека на одном смартфоне».
- ИИ: лёгкий (~0,5 с), средний (~2 с), сильный (~5 с).
- Составные ходы касаниями.
- Передача права хода пешке с обязательным завершением цепочки.
- Плавный поэтапный показ составного хода ИИ.
- Правильная визуальная последовательность передачи.
- Кнопки «Назад» / «Вперёд» для просмотра истории.
- Локальное сохранение и загрузка.
- Звуки обычного хода и взятия.
- После установки игра работает полностью офлайн.

## Управление

1. Коснитесь своей фигуры.
2. Зелёный — обычный завершающий ход.
3. Красный — взятие.
4. Синий — передача права хода дружественной фигуре.
5. После передачи выбирайте продолжение уже для новой активной фигуры.
6. «Отменить цепочку» отменяет незавершённый составной ход.

## GitHub Actions

Workflow `.github/workflows/android-apk.yml` автоматически собирает debug APK.

После загрузки проекта в репозиторий:
1. Actions → Build Android APK.
2. Run workflow.
3. После успешной сборки скачать artifact `RussianChess-Android-debug`.
4. Внутри находится устанавливаемый APK.

## Локальная сборка

На Linux/WSL:

```bash
buildozer -v android debug
```

Готовый APK появится в `bin/`.
